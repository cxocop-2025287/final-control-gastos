### 5. `services/auth.service.ts`
```ts
export class AppError extends Error {
  constructor(message: string, public statusCode: number, public errorCode: string) { … }
}

export class AuthService {
  static async login(data: ILoginRequest): Promise<ILoginResponse> { … }
  static async googleLogin(token: string): Promise<ILoginResponse> { … }
}
```
#### `login`
1. Busca usuario por nombre (`UserModel.findByName`).
2. Verifica `is_active` → 403 si false.
3. Compara contraseña con **bcrypt**.
4. Si falla → 401.
5. Genera **payload** `{ userId, name, role }`.
6. Firma JWT con `generateToken`.
7. Registra actividad (`registerActivity(user.id)`).
8. Devuelve `{ message, token, expiresIn, user }`.

#### `googleLogin`
1. **Carga dinámica** de `google-auth-library`.
2. Verifica ID token contra `env.GOOGLE_CLIENT_ID`.
3. Extrae `email` y `sub` (Google ID).
4. Busca usuario por `google_id` o por `email`.
5. Si no existe, crea usuario JIT con password aleatorio (hash bcrypt) y almacena `google_id`.
6. Genera JWT propio y registra actividad.
7. Devuelve respuesta idéntica a `login`.

  return jwt.sign(payload, env.JWT_SECRET, { expiresIn: env.JWT_EXPIRES_IN });

### 5. `pages/login/login.ts`
```ts
@Component({ … })
export class LoginComponent implements OnInit {
  config: Config | null = null;
  retry = 0;
  readonly MAX_RETRIES = 20;
  readonly RETRY_DELAY = 300; // ms

  ngOnInit() {
    this.loadConfig();
  }

  private async loadConfig() {
    this.config = await this.configService.loadConfig();
    this.initGoogleSignIn();
  }

  private initGoogleSignIn() {
    if (typeof (window as any).google === 'undefined') {
      if (this.retry < this.MAX_RETRIES) {
        this.retry++;
        setTimeout(() => this.initGoogleSignIn(), this.RETRY_DELAY);
      }
      return;
    }
    const google = (window as any).google;
    google.accounts.id.initialize({
      client_id: this.config?.googleClientId,
      callback: this.handleGoogleCredential.bind(this),
    });
    google.accounts.id.renderButton(
      document.getElementById('google-btn-container'),
      { theme: 'outline', size: 'large', type: 'standard' }
    );
  }

  private async handleGoogleCredential(response: any) {
    await this.authService.googleLogin(response.credential);
    this.router.navigate(['/dashboard']);
  }
}
```
- **Retry Loop** espera a que el script GIS (`window.google`) esté disponible.
- **RenderButton** inyecta un *iframe* seguro dentro `#google-btn-container`.
- **Callback** envía el JWT de Google a `AuthService.googleLogin`.

## Flujo típico de login con Google
1. Cliente carga `index.html` → script GIS.
2. `LoginComponent` solicita `/api/config` → obtiene `googleClientId`.
3. `initGoogleSignIn` entra en bucle de *retry* hasta que `window.google` está disponible.
4. Llama a `google.accounts.id.initialize` y `renderButton`.
5. Usuario pulsa el botón → GIS envía JWT al callback `handleGoogleCredential`.
6. `AuthService.googleLogin` envía credential al backend `/api/auth/google`.
7. Backend verifica token con Google, crea/encuentra usuario, genera JWT propio y registra actividad.
8. Front guarda JWT, inicia monitor de inactividad y redirige a `/dashboard`.
9. Cada interacción envía `heartbeat` al backend, que actualiza `last_seen`.
10. Si la inactividad supera `SESSION_INACTIVITY_TIMEOUT`, el monitor local ejecuta `logout()` y el backend retornará 401 para cualquier petición con token expirado.
