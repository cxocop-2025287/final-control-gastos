# Control de Gastos
## Descripción
Este proyecto consiste en una aplicación Web que pueda gestionar los gastos de los usuarios, pudiendo llevar sus finanzas y presupuestos de manera ordenada.

La aplicación sigue en proceso pero ya cuenta con la parte del login terminada.

## Tecnologías

Backend: Node.js, TypeScript, PostgreSQL, JSON Web Tokens  
Frontend Angular, TypeScript, HTML, CSS

## Requisitos 

- Node.js (18 o superior)
- pnpm (8 o superior)
- PostgreSQL (14 o superior)

## Instalación

Pequeña guia de como instalar la aplicación de manera local
- Paso 1: Clonar el repositorio https://github.com/cxocop-2025287/control-de-gastos
- Paso 2: Abrir una terminal, puede ser desde algún IDE
- Paso 3: Ir a la dirección donde clonaste el repositorio
- Paso 4: Crear una base de datos en pgAdmin4
- Paso 5: Configurar .env con los datos del usuario
- Paso 6: Entrar a la carpeta Back y ejecutar pnpm install,pnpm seed, pnpm run dev
- Paso 7: Desde otra terminal entrar a la carpeta front y ejecutar pnpm install, pnpm start
- Paso 8: Abir [localhost:4000](http://localhost:4200/login) desde un navegador
